# 클래스로(Classro) 회사 소개

> 수업용 가상 회사입니다. 등장하는 회사·인물·수치는 모두 지어낸 것이며, 실습 중 AI에 자유롭게 넣어도 됩니다.

## 한 줄 소개
동네 공방·작업실의 **원데이 클래스**(도자기, 베이킹, 가죽공예, 플라워, 드로잉, 향수)를 앱에서 찾고 바로 예약·결제하는 서비스.

## 기본 정보
| 항목 | 내용 |
| --- | --- |
| 설립 | 2023년 3월 |
| 대표 | 한서윤 |
| 직원 | 30명 (개발 11, 디자인 4, PO 3, 마케팅 5, 운영·CS 5, 경영지원 2) |
| 서비스 | iOS·Android 앱, 모바일 웹 |

| 월 예약 | 약 7천 건 (2026년 9월 기준) |
| 평균 결제액 | 1인 42,000원 |
| 수익 모델 | 예약 건당 수수료 15% |

## 핵심 사용자 흐름
방문 → 검색/탐색 → 클래스 상세 → 예약 시작(날짜·인원 선택) → 결제 → 예약 완료

## 이번 분기(2026년 4분기) 목표
1. **예약 전환율 회복**: 방문 대비 예약 완료율이 최근 4주 2.7%로 떨어짐(이전 4주 3.9%) → 3.9% 회복
2. 앱 리뷰 평점 4.5 유지
3. 마케팅 CAC(예약 1건당 광고비) 9,000원 이하
