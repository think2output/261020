# 클래스로(Classro) 홈페이지

수업용 가상 회사 "클래스로"의 소개 홈페이지를 5명이 한 페이지씩 나눠 만드는 실습 저장소입니다.

## 시작하기
```bash
git clone https://github.com/think2output/261020.git
cd 261020
git checkout feature/담당메뉴   # 브랜치는 이미 만들어져 있음
```
`index.html`을 브라우저로 열면 바로 보입니다. 따로 설치할 것은 없습니다.

**작업 전에 [RULES.md](RULES.md)를 꼭 읽어 주세요.** 담당, 브랜치, 공통 정보(주소·숫자)가 정리돼 있습니다.

## 폴더 구조
| 경로 | 내용 |
| --- | --- |
| `index.html` 등 5개 | 담당자별 페이지 |
| `style.css` | 공통 디자인 (조장만 수정) |
| `docs/00_회사소개.md` | 회사 기준 자료 |
| `data/` | 페이지에 쓸 데이터 (예: 리뷰 샘플) |
| `images/` | 이미지 |

## 쓸 수 있는 공통 스타일
`style.css`에 이미 있는 것만 쓰면 페이지끼리 모양이 맞습니다.

| 클래스 | 용도 |
| --- | --- |
| `.lead` | 제목 아래 소개 문단 |
| `.section` | 내용 덩어리 사이 간격 |
| `.cards` + `.card` | 카드 묶음 (휴대폰에선 1열) |
| `.btn` | 버튼 모양 링크·버튼 |
| `.info-table` | 정보 표 |
| `.map` | 지도 iframe 감싸기 |
| `.form-row` | 예약 폼 한 줄 (라벨 + 입력) |
| `.tag` | 알약 모양 라벨 (클래스 종류, 키워드 등) |
| `.band` | 색 띠 박스 (기본 그린 / `.band--dark` `.band--lime` `.band--pink`) |
